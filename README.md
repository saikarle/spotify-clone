# 🎵 Spotify Clone

A Spotify-inspired music player built using **HTML, CSS, and JavaScript**. I created this project to recreate the look and feel of the original Spotify music player while learning how music playback and player controls work.

## ✨ Features

- Spotify-inspired user interface.
- Add and organize songs in music libraries.
- Play and pause songs.
- Next and previous song controls.
- Volume control to adjust the music level.
- Track current song and playback progress.
- Display song duration and current playback time.
- Responsive design for different screen sizes.
- Browse and play songs from different playlists.

## 🛠️ Technologies Used

- **HTML** – For structuring the application.
- **CSS** – For designing the user interface and making it responsive.
- **JavaScript** – For music playback, song tracking, volume control, and interactive functionality.

## 📚 What I Learned

While building this project, I learned how to implement music player functionality using JavaScript and improved my logical thinking and problem-solving skills.

Some key concepts I practiced:

- Working with the JavaScript Audio API.
- Playing, pausing, and switching between songs.
- Tracking the current song and playback progress.
- Implementing volume controls.
- Handling events and user interactions.
- Dynamically adding songs to playlists.
- Fetching and managing song data.
- Making the application responsive using CSS.

## 🎯 Project Purpose

I built this project to improve my JavaScript skills through practical implementation. My main focus was understanding the logic behind a music player, especially how to control volume, track songs, manage playlists, and handle audio playback.

This project helped me understand how real-world music player applications work.
